CONSERVARE SUL PC
Scarica questo ZIP e salvalo in una cartella del computer.
Per lavorare sul sito, fai clic destro sullo ZIP e scegli Estrai tutto.
Conserva anche una copia dello ZIP originale come backup.

PUBBLICAZIONE SU UN ALTRO HOSTING
Carica tutti i file web e la cartella assets nella cartella pubblica del tuo
hosting statico. index.html deve trovarsi nella radice. Mantieni i nomi e
la struttura delle cartelle. LEGGIMI.txt e CHECKSUMS.sha256 sono documenti
di accompagnamento e non sono necessari per pubblicare il sito.
Non occorrono compilazione, database o abbonamento ChatGPT per eseguire
questi file su un altro hosting statico.

ANTEPRIMA SU WINDOWS
Il lettore interattivo carica laws.json e richiede un server HTTP locale.
Se hai Python 3, apri un terminale nella cartella estratta ed esegui:

py -m http.server 8000

Poi visita nel browser:
http://localhost:8000

Se il comando py non è disponibile ma Python è installato, prova:
python -m http.server 8000

Premi Ctrl+C nel terminale per fermare il server.
Con il semplice doppio clic su index.html il browser può bloccare il
caricamento delle leggi. leggi.html contiene comunque tutti i testi.

I collegamenti Amazon e Facebook richiedono Internet.
La cancellazione del sito ChatGPT non modifica copie pubblicate su altri
hosting, né cancella i documenti e i backup separati.
